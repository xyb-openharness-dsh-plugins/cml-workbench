## 4. 差异评价（与 26 号口径、家族基准对照）

- **与家族基准的差异**：乳腺/卵巢/肺癌的 HVT 主轴是"解剖后果 + 部位转移"；CML 主轴是**"分子数值可比性 + 每日口服依从 + 停药尝试"**——一级重名率实测 **45.8% ≤70%**（research/family-comparison-cml.md），3 条家族空位线（处方变更/TFR/费用）在本仓有独立承载。
- **A2 轴主动记"无显著差异"**：本报告最重要的自律项——避免为凑轴数把"术后恢复"套到 CML 上（=换名复用）。
- **医学口径最强背书**：指南原文"不建议根据 BCR::ABL1 IS 的单次、单一数值做出转换治疗的决策"直接支撑 HVT-07 形态（分段 + 四要素）与 ACC-H12（依从并列），也支撑"本仓零判读"红线。
