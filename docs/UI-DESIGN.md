## 二、业务容器与宿主布局

- `customFrame: true`；业务区与原生会话区共用顶栏；**会话区默认 35%、范围 25%–45%、可拖可收**（唯一来源 `lib/layout.js`）。
- 拖拽分隔器可键盘操作（←/→ 步进 1%，Home/End 到边界）；偏好持久化到本机 profile；**split 形态不另造宽度状态**。
- 业务区最小可用宽度 720px；窄于此宽度转为单列 + 纵向堆叠（见 §六）。
- **页脚贴底**：版本号 + 构建日 + 数据目录状态常显。

## 三、语义 token / 字体 / 间距

- 字号：正文 **13px**、次要 12.5px、标题 15px（**全站 12.5–15 区间，无例外**）。
- 颜色：仅用语义 token（`--fg`/`--bg`/`--muted`/`--line`/`--accent`/`--warn`）；**不使用"红=坏/绿=好"这类判读色阶**；趋势线单色、参考线虚线灰。
- 间距 4 的倍数；卡片圆角 8px；表格行高 ≥32px。
- 数字：`tabular-nums`；数值与单位同一行不折行。

## 四、关键交互与状态

| 场景 | 加载 | 空态 | 单条数据 | 错误 |
| --- | --- | --- | --- | --- |
| 分子线趋势 | 骨架条 | "还没有分子结果，先记一笔复查" + 手工入口 | 单点不画线，只显示点 + "再记一次才成趋势" | 拒收候选零副作用；保留草稿 |
| 服药打卡 | 立即（本地） | 首次显示"今天还没记" | 单日一格 | 本地写失败 → 提示重试，不丢输入 |
| 副作用日志 | 无需 | 词表引导（按当前药） | 单条时间线 | 同上 |
| TFR 清单 | 无需 | 未开始核对 | 每项三态（已确认/未确认/不适用） | 不满足只显示缺哪些字段 |
| 资料导入 | 解析进度 | 拖放区 | 单文件直接进核对 | 解析失败 → 手工补录，不报"成功" |
| 值得报告的信号卡（HVT-11） | 无需 | 还没有记录信号 | 静态事实清单，来源版本随条显示 | 来源未核实 → 标「未核验」，不给个体判断 |

- **结果回顾**：每次写入完成后 Toast 内嵌「回到看板」（一步回首页），不阻断操作。
- **`[hidden]`**：一律原生 `hidden` 属性 + `[hidden]{display:none!important}`，不用 `opacity:0` 假装隐藏。
- **显式编辑 ≤1/页**：主编辑动作只保留一个入口，其余收进卡片「⋯ 更多」。
- **数字输入用键盘组件**（`inputmode="decimal"`），不用纯滑块替代精确输入。
- **删除 = 更正**：界面只出现"改这一条/更正"，历史版本同链可回溯；无"不可恢复"文案。
- **无判读列**：任何表格/卡片不出现"达标/未达标/正常/异常/风险/建议"列或色块。
- **减少动效**：`prefers-reduced-motion` 下取消过渡；图表无入场动画。

## 五、AI 面板与草稿

- 顶栏「AI 对话」拉起原生会话；默认关；状态文案：未连接/连接中/已连接/不可用（不用"在线"这类含混词）。
- 隐藏面板**不结束会话、不清空**筛选/表单/滚动/草稿；重开复用同一会话。
- 一键带上下文：按钮发 `cml:agent-draft`，携带**当前页 + 时间区间 + 相关记录摘要**（敏感线默认不带，见 §七）；提示词进输入框**不自动发送**。
- 生成物一律进"候选 → 逐项核对"通道；**TFR 与生育两线不提供 AI 生成**（红线：重大决策不 AI 生成）。

## 六、窄宽与大字（30 号第一版）

- ≤ 900px：右侧会话区可收为图标；业务区单列。
- ≤ 720px：卡片全宽、表格转键值行、趋势图固定最小高度 180px 并允许横向滚动（不压缩 X 轴标签）。
- 大字（浏览器 125%/150%）：不出现横向滚动条；页脚版本号常驻；按钮触控高度 ≥44px。

## 七、隐私与三出口（private 代码级过滤）

- 三出口＝**导出 / AI 上下文 / 摘要**；敏感线（生育计划、费用）默认不进 AI 上下文，用户显式勾选才带；过滤在代码层（可断言），不靠文案。
- 双主体：`author_role`（本人 / 家属代记）+ `visibility`；代记条目界面有明确来源标记（不隐藏、不混淆）。

## 八、设置弹窗（CML-CFG）

分区：① 患者资料目录（当前路径 + 迁移边界 + 状态）；② API 凭据（只显示"已配置/未配置"，**不显示明文**）；③ 临床参考数据包（来源/版本/状态，M4 后填实际值）；④ 关于（版本/构建日/渠道/来源/免责声明）。
保存/取消/错误恢复：保存失败保留输入并可重试；取消不写库；凭据写入 Token 文件优先、`.gitignore` 覆盖 `.secrets`。
