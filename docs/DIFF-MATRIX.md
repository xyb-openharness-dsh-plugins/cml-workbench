## 差异化矩阵（场景 → 功能 → 怎么验）· 承接认领 Issue #31 六条

1. qPCR 趋势线 + 里程碑词表卡 → 验收：无 diagnosis/risk_level 判读列、三态、分类不进趋势
2. 每日服药打卡 + 处方变更线 → 验收：日历热力图 + 变更事件同库同源
3. 副作用自评日志 → 验收：时间线可导出、无判读词
4. TFR 档案 + 密测轨道 → 验收：独立事件轨道、不写建议文案
5. 用药费用记录 → 验收：按月聚合不跨药混算
6. 生育计划资料夹 → 验收：红线扫描、纯问题清单形态

## 一级重名率实测 ✅（2026-10-25，三路调研·家族对比线）

- 实测：**5.5 / 12 = 45.8% ≤ 70%，家族判据合格**。基准：cervical 一级 12 条、breast v0.12.0 一级 8 条（27 个二级），一级清单取自两仓代码实测（cervical `public/app.js` PAGES；breast SPEC 与代码一致）。
- 逐条：同名 2（复诊准备、设置）· 近义 0.5×7 · 无关 3（**处方变更 / TFR档案 / 费用记录 = 家族空位**，差异化主张成立）。
- 敏感性：从严 33.3% / 从宽 62.5%，三口径均过，结论稳健。
- 完整判定表与两仓一级清单原文：`research/family-comparison-cml.md`。
- ⚠️ G1 决策点：一级 12 条超 26 号建议的 8–10 条。预案：处方变更并入服药线（作分段视图）、复查记录并入分子线（作二级）→ 10 条，重名率仍 ≤70%。待用户裁决。
