## 一、总原则（本仓签认版）

- AI 协助默认：说 / 拍 / PDF（MinerU）→ 结构化候选 → **逐项核对** → 确认才入事实层；拒收零副作用。
- 手工永远可及但收敛：「⋯ 更多」收口；每页显式编辑 ≤1；表单 ≤6 字段；数字用键盘组件。
- 删除 = 更正：只新增版本；界面语言"改这一条"，无"不可恢复"。
- 回首页一步：二级页返回 / 顶栏品牌「小粒宝」/ 完成 Toast 内嵌。
- CML 专属：qPCR 数值**只抄报告原文**（值+单位+实验室名+日期），本仓不做任何 IS/非 IS 换算判读；衍生对数刻度仅图示层。
