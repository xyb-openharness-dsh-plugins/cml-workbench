# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：CML（慢性粒细胞白血病）患者本人为主体，家属/照护者代记为第二主体

场景：慢性期全程管理（确诊→TKI 治疗→换线/副作用/费用→TFR 停药尝试与密测）的本机资料整理、趋势回顾与就诊准备

核心流程：
1. 录入/导入一次复查报告（血常规、qPCR BCR::ABL1 IS%）并回看在分子趋势线上的位置
2. 记录今日 TKI 服药与副作用，回顾月度依从与副作用时间线
3. 复诊前生成问题清单与资料包，就诊后补充医嘱原文与换线记录

完成结果：患者能在复诊前把'我的分子线走势 + 我这段时间吃了什么药、有什么反应 + 我要问什么'一次性讲清并带走

初始布局选择：business-first
