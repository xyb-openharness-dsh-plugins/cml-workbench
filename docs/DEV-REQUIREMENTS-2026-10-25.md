## 七、M2 本轮踩出的三条新坑（2026-10-25，进检查器）
1. **"自检清单写 0 ≠ 真的是 0"**：原型 index.html 文末曾写「复发 0」，实测渲染出 1 处非引用命中。教训：自查声明必须由脚本从**渲染态**生成，或至少渲染态复算；手写声明一律视为未验证。检查器已固化：`scripts/probe-write-paths.py` W6（展开全部 `<details>` 后扫 `innerText`）。
2. **源码 grep 测不出"入口存在但点不到/写入不产生记录"**：首轮自建检查器全绿，独立评审实跑 109 条 DOM 断言后判 P0=11。教训：原型闸口的证据必须是**点击级**断言（提交前后计数、跨档案草稿、导出块构成），源码字符串只作补充。检查器已固化：`scripts/probe-ip-matrix.py`（X1–X4 + 入口逐字可点）、`scripts/probe-write-paths.py`（W1–W6）。
3. **修 P0 会引入新缺陷**：11 条修完后 420px 下分子线明细表溢出 32px（表格未按 30 号转键值行）。教训：任何修复后必须**复跑全宽度矩阵**，复审不可省；窄宽断言要包含"展开折叠卡后"的状态。检查器已固化：`scripts/probe-page-view.py`（4 档 × 10 页 × 展开态）。

### M2 增补轮（2026-10-25，用户三条新需求）新增的坑

9. **规范是设计稿，不是实现**：MATCHING-SPEC 写于 2026-10-13、标注「设计建议稿」，家族里只有 gtn-workbench 实现过。
   照规范写代码前必须先去实现仓核对一遍版式与字段名（例如「匹配指数」实为**入组档案完整度 x/y**，不是匹配度百分比）——
   只读规范很容易照着"匹配度"去写，直接踩 27 号「页面里不得出现综合评分」的验收红线。
10. **免责措辞本身会踩禁词表**：写「本清单不含『是否满足』结论」时，那句话里的「满足」被自家禁词扫描命中。
   凡是否定式说明，必须改写为不含禁词的说法（「本清单不给结论」），否则自检与页面纪律互相打架。
11. **字号豁免必须逐选择器声明**：24 号要求数字约 33px，而正文只允许 12.5–15px。检查器不能按"值"放行（那等于取消断言），
   必须按"选择器"单点豁免（`NUMERAL_SELECTORS = ['\.mval']`），且豁免清单要能在本文件查到来源。
12. **新页是孤儿页的高危来源**：加页面很容易忘记加入口。`probe-ip-matrix.py` 的 X1 用「无入站链接 或 无场景路径经过」双口径判，
   新页必须同时在**代码**（看板/相关页的 `<a href>`）与**文档**（`INTERACTION-DESIGN.md §二 场景路径表` 的入口文案）里出现，缺一边就报孤儿。
13. **两个探针的路由表是手写的，会漏新页**：`probe-page-view.py` / `probe-ip-matrix.py` / `probe-write-paths.py` 各有独立 `PAGES` 常量，
   加路由时必须三个都改，否则新页不参与宽度/溢出/禁词/IP 扫描——"检查器全绿"可能只是因为它没看那一页。
14. **数据字段名以 demo 为准，不要凭印象写**：数据点字段是 `d`（不是 `date`），凭 API 直觉写会全站 `undefined` 且不报错。
   凡新增渲染函数，先在浏览器里看一眼首屏有没有 `undefined`。
15. **注释与数据必须同时改**：A 档案注释写「8 月起换实验室（不可比）」但四条记录同实验室，导致"不可比"演示开关形同虚设。
   注释里的断言要么被数据支撑，要么就别写；这类不一致检查器抓不到，只有人（或做对照实验）能发现。
16. **断点要照规范的断言值反推**：27 号 §4.3 断言是 1440/1080/860 → 列数 2/2/1，等价于断点取 960px；
   按"感觉"写 700px 会让 860px 档变两列、三档断言直接不过。
