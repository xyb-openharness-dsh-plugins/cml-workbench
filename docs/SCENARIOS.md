# SCENARIOS · CML 一期场景清单（🔧 M0 骨架，G1 与 PATIENT-FLOW/INTERACTION-DESIGN 同批签认）

> 场景 = 患者带着什么来、走哪条线、拿走什么。P0=一期必做，P1=一期可要点式，P2=不进一期。
> 每条场景 ID 与 INTERACTION-DESIGN 路径表、FEATURE-INVENTORY 一一对应（IP2 无孤儿页）。

## P0（一期核心闭环）

| ID | 场景 | 触发 | 路径概要 | 可观察产物 |
| --- | --- | --- | --- | --- |
| S1 | 录入一次 qPCR 复查结果 | 拿到报告 | 看板「分子线」→ 拍/PDF 候选 → 逐项核对 → 入库 | 趋势图新增一点（抄录值+单位+实验室原文） |
| S2 | 记录今日 TKI 服药 | 每天 | 看板「今日」→ 一键打卡 / 漏服标记 | 当日依从状态 + 日历热力 |
| S3 | 记一次副作用 | 不适发生时 | 看板「副作用」→ 选词 + 日期 + 自评（无严重度判读） | 时间线一条 + 与用药的并列视图 |
| S4 | 处方变更（换药/调剂量） | 医生改方案 | 「服药线」→ 变更事件（药名/剂量/起止/原因原文） | 变更线 + 与分子点的时间关系可看 |
| S5 | 复诊准备包 | 复诊前 1–2 天 | 首页「准备复诊」→ 选区间 → 生成资料包 + 问题清单草稿 | 可导出 bundle（private 过滤生效） |
| S6 | 里程碑词表查阅 | 报告上出现 MMR/MR4.5/IS% | 任意趋势页「这个词什么意思」→ 词表卡 | 词义 + 来源版本，**无"你达标了"判读** |

## P2（不进一期，理由）
- 加速期/急变期临床决策支持（越红线：本仓不做处置建议，仅资料归档能力已在 S5 覆盖）
- 与他人共享的长期公开主页（隐私模型未验，先不做）
- 自动预约/挂号（宿主无此合同）

## 双主体
所有 P0/P1 场景须可在「患者本人」与「家属代记」两种 author_role 下完成；代记可见性默认与本人一致，敏感线（生育计划）默认 private。
